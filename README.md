## OpenAction Discord plugin

An OpenAction ([OpenDeck](https://github.com/nekename/OpenDeck) / [Tacto](https://tacto.rivul.us)) plugin for controlling the Discord desktop client

#### Actions

- Toggle Mute
- Toggle Deafen
- Push to Mute
- Push to Talk
- Toggle Voice Input Mode
- Toggle Video
- Toggle Screen Share
- Volume Control
- User Volume Control
- Set Audio Device
- Text Channel
- Voice Channel
- Soundboard
- Notifications
